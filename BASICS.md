# SACFunDay – Simple Guide (Bullet Points)

SACFunDay is a website that helps St. Augustine’s Chapel run its annual Fun Day.  
Here is what the main functions are, explained in plain language from two points of view.

## From a Parent’s or Participant’s Perspective

- Sign up your children (and sign up yourself if you are an adult) during the open registration period.
- For each person, choose up to 4 games or races they want to join.
- Immediately after signing up, receive one **Master QR code** per person. This single code works at every game station that person is registered for.
- Save the QR code or take a clear screenshot of it.
- On the day of Fun Day, show your Master QR code when you arrive at each station.
- If you lose or forget your QR code, go to the “Retrieve Your QR Code” page and enter your phone number + full name (or just your name + year of birth as a backup). No password is needed.
- One parent or guardian can register several children at the same time in one form.

## From the Organizing Committee’s (OC) Perspective

- Create and manage the list of games (events) and decide which age groups can take part in each game.
- Open or close the parent sign-up portal whenever you want.
- View the complete list of all registered participants and their chosen events.
- On the actual day of Fun Day:
  - At each game station, scan a participant’s Master QR code with the phone camera or type the code in manually to check them in.
  - Enter results quickly using large, easy-to-tap buttons (for 1st place, 2nd place, etc., or mark “Did Not Finish”, “Did Not Start”, etc.).
  - When marshals hand in paper result slips, type those results into the system and mark them as “Paper” so everyone can see the source.
  - See a live progress bar (for example: “18 out of 32 results entered”).
  - Use the “Undo” button to fix the most recent mistake on any result.
  - View who entered each result and exactly when it was entered (for records and fairness).
- Set the name of the person who is currently entering results (this name appears on all new entries).
- Add, remove, or import participants (for example from a spreadsheet) if last-minute changes are needed.
- Control basic event day settings such as the event title and date.

## Key Things That Make Life Easier

- One Master QR code per person — no one has to keep track of many different codes.
- Adults can fully take part in the day (they are treated the same as children).
- The system works with both phones/tablets **and** traditional paper notes.
- Everything is designed to be used outdoors on phones with big buttons and simple steps.

For any questions, please contact St. Augustine’s Chapel.
